MANISH SINGH — PORTFOLIO
=========================

Files:
- index.html  -> main website
- style.css   -> styling and responsive layout
- script.js   -> mobile menu + small animations

How to run:
1. Keep all three files in the same folder.
2. Double-click index.html to open it in a browser.

How to publish:
- GitHub Pages: upload these files to a GitHub repository and enable Pages.
- Netlify/Vercel: drag the folder into the service or connect the GitHub repo.

Before publishing, consider replacing the placeholder portfolio URL from your resume
with the final URL after you deploy the site.
